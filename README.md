# 거래소별 시총 순위 보드

[index.html](C:\Users\wlvht\Documents\Codex\2026-04-22-spot-usdt\index.html) 를 브라우저에서 열면 됩니다.

`file://` 로 열면 거래소 API가 차단될 수 있습니다. 그 경우 `server.ps1` 로 로컬 서버를 띄운 뒤 `http://127.0.0.1:8791` 로 여는 방식이 더 안정적입니다.

포함된 기능:

- 바이낸스 `USDT` 현물 시총 순위
- 업비트 `KRW` 마켓 시총 순위
- 빗썸 `KRW` 마켓 시총 순위
- 100개 단위 페이지 이동
- 동시상장 종목 필터
  - 바이낸스 + 업비트 + 빗썸
  - 바이낸스 + 업비트
  - 바이낸스 + 빗썸

데이터 방식:

- 거래 가능 종목 목록은 각 거래소 공개 API 기준입니다.
- 시총은 CoinGecko 유통량과 각 거래소 현재가를 곱해서 계산합니다.
- 동시상장 여부는 심볼 기준으로 판별합니다.

체인 수수료:

- 자료의 `L1 수수료`, `L2 수수료`는 DefiLlama의 체인 자체 수수료(USD)를 24시간, 7일, 30일 기준으로 표시합니다. 체인 내 앱의 수수료 합계가 아닙니다.
- 검토한 체인 분류 목록 전체를 표시하며 25위 제한은 없습니다. L3, 사이드체인 및 분류가 불확실한 체인은 L1로 추정하지 않습니다. 데이터가 없는 값은 `-`입니다.
- 로그인한 회원만 조회할 수 있습니다. 두 화면은 서버의 10분 캐시와 진행 중 요청을 공유하며 실패하면 마지막 정상 데이터를 유지하고 1분 뒤 재시도합니다.
- 원본: https://defillama.com/fees/chains / 정의: https://docs.llama.fi/analysts/data-definitions

주의:

- 같은 심볼을 여러 프로젝트가 공유하는 경우 CoinGecko 매칭 오차가 생길 수 있습니다.
- `file://` 환경에서 브라우저 보안 정책이나 거래소 CORS 정책 때문에 일부 API 호출이 막힐 수 있습니다.
